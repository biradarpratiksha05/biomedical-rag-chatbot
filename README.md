# 🧬 Biomedical RAG Chatbot

A Retrieval-Augmented Generation (RAG) based chatbot designed to answer scientific and biomedical questions using relevant biomedical literature.

The system retrieves relevant evidence, generates concise answers, displays similarity scores, and provides an evidence reliability label.

## 🎯 Objective

The objective of this project is to develop a biomedical question-answering system that combines information retrieval and generative AI to provide concise, evidence-supported answers to scientific questions.

## 🧠 How It Works

```text
User Question
      ↓
Query Processing
      ↓
Biomedical Literature Retrieval
      ↓
Semantic Similarity Ranking
      ↓
Top 3 Evidence Chunks
      ↓
Answer Generation
      ↓
Evidence Reliability Assessment
      ↓
Final Answer + Evidence
